GitHub token needed

Create a fine-grained personal access token with read-only access to Metadata, Pull requests, Contents and Commit statuses. Fine-grained tokens can't read individual Actions check runs (the overall CI state still shows); a classic token with repo scope can. Tokens are kept in this browser's localStorage and only ever sent to the GraphQL API of the host they belong to.

A fine-grained token reaches one user or org, so add one token per org you want here. If an org requires approval for fine-grained tokens, its PRs stay missing until an admin approves. For GitHub Enterprise, enter the host (for example acme.ghe.com) and create the token at https://<host>/settings/personal-access-tokens/new.
